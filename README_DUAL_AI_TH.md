# V7.9 — เลือกใช้ Grok หรือ Veo ในเว็บเดียว

1. เปิด `run_windows.bat` แล้วเข้าเว็บ `http://127.0.0.1:8010`
2. สมัคร/ล็อกอิน → **API ของฉัน** → ใส่คีย์ของ **xAI / Grok Imagine** หรือ **Google Gemini / Veo** ในช่องแยกกัน
3. เพิ่มสินค้าของฉัน → สร้างบทรีวิว → เข้า **AI Video Lab**
4. เลือกบริการและโมเดล (Grok 1.5 Lite / Grok 1.5 / Google Veo 3.1), ใส่หรือไม่ใส่ภาพอ้างอิงแนวตั้ง 9:16 แล้วเลือกบท
5. ติ๊กยืนยันค่าใช้จ่าย → กดสร้าง → รอสักครู่แล้วกดตรวจสถานะ → เมื่อเสร็จ ดู MP4 และส่งเข้าคิว

## ข้อจำกัด
- Grok ตั้ง 10 วินาที 720p, Veo ตั้ง 8 วินาที 720p; หาก Grok ใช้รูปเป็นเฟรมแรก วิดีโอจะมีสัดส่วนตามรูป ดังนั้นควรใช้ภาพแนวตั้ง 9:16
- ผู้ใช้รับผิดชอบค่า API ของผู้ให้บริการแต่ละราย; คีย์จากบัญชีเว็บ Grok หรือเครดิต Flow ไม่ได้หมายความว่าได้สิทธิ์ API
- ระบบไม่สามารถพิสูจน์ผลจริงโดยไม่มีคีย์ที่มีเครดิต จึงทดสอบผ่าน API จำลองเท่านั้น
- วิดีโอที่ AI สร้างต้องตรวจสินค้าตรงรุ่นและปฏิบัติตามนโยบาย AI-content ของแพลตฟอร์มก่อนเผยแพร่
- บริการ xAI ส่งลิงก์ไฟล์อาจหมดอายุ ระบบจึงเก็บ MP4 ทันทีเมื่อผู้ใช้ตรวจพบว่าสร้างเสร็จ
- ระบบยังเป็น Beta สำหรับเครื่องทดสอบ; อย่าปล่อยสาธารณะโดยไม่ทดสอบสิทธิ์ ความปลอดภัย ระบบสำรองข้อมูล และโหลดจริงบน Cloud
- แพตช์ออฟไลน์ยังไม่ลงลายเซ็นผู้พัฒนา ใช้เฉพาะไฟล์จากแหล่งที่ไว้ใจ
