# ขั้นตอนออกรุ่นสำหรับผู้พัฒนา (อย่าแจกไฟล์แพตช์ที่ไม่ผ่านการทดสอบ)

1. เก็บสำเนารุ่นก่อน เช่น `studio-v7.2` และเตรียมรุ่นใหม่ `studio-v7.3`.
2. อัปเดต `version.json` ของรุ่นใหม่ให้เป็นเวอร์ชัน X.Y.Z; เพิ่ม release notes และทดสอบการ migrate DB ด้วยข้อมูลสำรอง (ห้ามให้ patch ทับ data).
3. รัน `python developer_tools/build_patch.py --old "..\studio-v7.2" --new "..\studio-v7.3" --output "..\releases\studio_update_0.7.2_to_0.7.3.zip"` จากโฟลเดอร์รุ่นใดก็ได้ที่มี tools.
4. ทดลองติดตั้งแพตช์ใน **สำเนา** รุ่นก่อน โดยมีฐานข้อมูลทดลอง แล้วรัน smoke test, ทดสอบกู้คืน และเช็กว่าคีย์ยังอ่านได้.
5. แจกผ่านช่องทางทางการเท่านั้น; ควรลงลายเซ็นไฟล์แบบเข้ารหัสก่อนแจกจริง. แสดง SHA256 แยกจากไฟล์ไว้สำหรับตรวจไฟล์เสีย.
6. ประกาศรายการแก้ไข (`CHANGELOG.md`) และนโยบายรองรับการอัปเดต รวมถึงวิธี rollback.

**คำเตือน:** ระบบ patch ปัจจุบันยังไม่ได้ตรวจลายเซ็นผู้เผยแพร่และไม่ควรใช้สำหรับให้คนทั่วไปติดตั้งแพตช์จากอินเทอร์เน็ตโดยไม่ตรวจสอบ.
