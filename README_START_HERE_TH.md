# Affiliate Auto Studio V7.9 — สร้างคลิปในเว็บด้วย Google Veo API

1. สำรองโฟลเดอร์ `data` และปิดเซิร์ฟเวอร์รุ่นก่อน
2. ใช้แพตช์ `0.7.7_to_0.7.8` ผ่าน `updates/inbox` + `update_windows.bat` หรือใช้ ZIP ตัวเต็มโดยย้าย `data` เดิมตามคู่มือ
3. เปิด `run_windows.bat` แล้วเข้า http://127.0.0.1:8010
4. สมัคร/ล็อกอิน → เมนู “API ของฉัน” → Google Gemini / Veo → บันทึก Gemini API key ของตัวเอง (ห้ามใช้รหัสผ่านหรือ OTP)
5. เพิ่มสินค้า → AI Video Factory สร้างบท → เมนู “สร้างคลิป AI” → เลือกบท/รูป → ติ๊กยินยอมค่าใช้จ่าย → สั่งสร้าง → กดตรวจสถานะจน MP4 พร้อม
6. ดูคลิปในเว็บแล้วเลือกส่งเข้าคิว TikTok/Shopee สำหรับลงเอง เมื่อแพลตฟอร์มอนุญาตสิทธิ์โพสต์ในอนาคตจึงค่อยเปิดออโต้ได้

**สำคัญ**
- Google Veo ผ่าน Gemini API เป็นการคิดค่าใช้จ่าย API แยกจากเครดิต Flow ต้องมีสิทธิ์โมเดลและเครดิต/การชำระเงินในบัญชี Google เอง
- รุ่นนี้ตั้งค่าคลิป 8 วินาที 9:16 สูงสุด 3 งานต่อวันต่อบัญชี และทำพร้อมกันได้ 1 งาน
- ส่ง Prompt และรูปไปที่ Google เพื่อสร้างคลิป Veo จะใช้ภาพที่แนบเป็นเฟรมเริ่มต้น จึงห้ามใช้ภาพหน้าร้านหรือ screenshot listing และควรใช้รูปสินค้าเดี่ยวที่มีสิทธิ์
- งานจะรอการตรวจสถานะด้วยปุ่ม “ตรวจสถานะ” (ยังไม่ได้ตั้ง background worker สำหรับการติดตั้งหลายเซิร์ฟเวอร์)
- OpenAI ยังเป็นช่องเก็บคีย์ (ไม่ได้ใช้สร้างวิดีโอ), Brave Search เป็นคีย์ค้นเว็บ, TikTok/Shopee ต้องขอสิทธิ์เชื่อมอย่างเป็นทางการ
- ยังไม่ได้ทดสอบสร้าง MP4 ด้วยคีย์ Google ที่มีสิทธิ์จริง ชุดทดสอบใช้งานจำลอง API ของผู้ให้บริการโดยไม่คิดเงิน
- ระบบบน Windows ยังเป็นโหมด local และไม่ควรเปิด port forwarding ให้คนภายนอกใช้งาน ห้ามเผยแพร่คีย์และไฟล์ข้อมูล
- การนำขึ้น Cloud ต้องเพิ่มระบบสำรองไฟล์วิดีโอที่เก็บถาวร การจัดงานค้าง การทดสอบโหลด/สิทธิ์ OAuth ก่อนเปิดให้คนทั่วไป
