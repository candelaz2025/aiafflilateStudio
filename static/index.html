▣ สแกน/นำเข้าข้อมูล Shopee Affiliate

เปิดบัญชี Shopee ของตัวเอง แล้วนำข้อมูลที่คัดลอกหรือรายงาน CSV มาอ่านในหน้าเว็บนี้ ไม่ต้องให้รหัสผ่านกับเรา

เปิด Shopee Affiliate ↗
หมายเหตุ: เว็บเรา ไม่ได้เข้าถึงแท็บ Shopee ที่ล็อกอินแทนคุณ และยังไม่ใช่ระบบดูดข้อมูลจาก Shopee โดยตรง ปุ่มสแกนด้านล่างอ่านเฉพาะข้อมูลที่คุณใส่หรือไฟล์ที่คุณเลือกเท่านั้น

Shopee มีรายงาน CSV อย่างเป็นทางการ หากมีคอลัมน์ชื่อสินค้า ระบบจะอ่านและแสดงตัวอย่างได้สูงสุด 100 รายการ

ยังไม่ได้เริ่มสแกน · ข้อมูลจะไม่ถูกบันทึกจนกว่าจะเลือกสินค้า
กรอกชื่อสินค้าแล้วกดค้นหาได้เลย · ไม่ต้องมี Brave API ก็เริ่มค้นข้อมูล RSS สาธารณะได้
EXTRA COMM Hunter: ค้นเฉพาะเบาะแสที่กล่าวถึงค่าคอมพิเศษจากผลเว็บ ไม่ใช่การยืนยันสิทธิ์ในบัญชี Shopee ของคุณ วิธีตรวจจาก Shopee Affiliate ↗
ต้องการเพิ่มโอกาสพบลิงก์สินค้าจาก TikTok/Shopee? สมาชิกสามารถใส่ Brave Search API key ของตัวเองในเมนู “API ของฉัน” ได้ ผลค้นหาไม่สามารถยืนยันยอดขายหรือค่าคอมได้

◷ ติดตามการนำสินค้าทำซ้ำ

สร้างสคริปต์สินค้าเดิมครั้งใหม่ ระบบจำวันเวลาแต่ละครั้ง · ติดตามผลต่อคลิปได้

กด “ทำคลิปใหม่” ในเมนูสินค้าของฉัน จะสร้างสคริปต์ใหม่และบันทึกเวลาทันที ยอดวิว/คลิก/ออเดอร์/ค่าคอมเป็นข้อมูลที่สมาชิกกรอกเอง ไม่ได้เชื่อมสถิติจริงจาก Shopee/TikTok และไม่ใช่การโพสต์อัตโนมัติ

บันทึกผลงานต่อคลิป

กรอกตัวเลขสะสมของคลิปนั้น — การบันทึกซ้ำจะอัปเดต ไม่บวกยอดซ้ำ

▣ AI Video Factory

สร้าง Hook บทรีวิว และ Prompt POV สำหรับสร้างวิดีโอด้วย AI ในเว็บ

ส่วนนี้สร้างบทแม่แบบฟรี · หากต้องการ MP4 ให้เข้า “สร้างคลิป AI” แล้วเชื่อม API ของตนเอง (OpenRouter, Google Veo หรือ xAI Grok)

🎬 สร้างวิดีโอด้วย AI ในเว็บ

เลือก Veo 8 วินาที, Grok 10 วินาที หรือรุ่นต่าง ๆ ผ่าน OpenRouter 8 วินาที แนวตั้ง 9:16 · มีค่าใช้จ่ายตามเครดิต API จริง · เครดิต Google Flow ไม่ใช่เครดิต API

สร้างคลิปใหม่

ใช้เครดิต API ของคุณเอง มีค่าใช้จ่ายตามผู้ให้บริการและรุ่นที่เลือก

โหมด “ฟรีจากระบบ” ไม่ต้องใช้ API key (มีโควตาจำกัด) · ผู้ให้บริการอื่นต้องมี xAI, Gemini หรือ OpenRouter API key ของคุณเอง พร้อมเครดิต/สิทธิ์: ตั้งค่าในเมนู API ของฉัน · Beta จำกัด 3 คำขอต่อวัน/สมาชิก และทำพร้อมกัน 1 คลิป

สถานะและผลลัพธ์

กดตรวจสถานะเมื่อรอประมาณ 10–30 วินาที · หากเสร็จแล้วดูคลิปหรือโหลด MP4 ได้จากบัญชีนี้

ยังไม่มีงานสร้างวิดีโอ

▦ คิวคลิปของฉัน

บันทึกงานรอโพสต์ TikTok/Shopee โดยไม่ปะปนกับสมาชิกคนอื่น

ยังไม่โพสต์อัตโนมัติ · เปิดแอป TikTok/Shopee แล้วโพสต์เอง จากนั้นกลับมาบันทึกสถานะในคิวนี้

คิวนี้เป็นเช็กลิสต์เตรียมโพสต์ ไม่ใช่ระบบอัปโหลด/ปักตะกร้าอัตโนมัติ การกด “ลงแล้ว” เป็นเพียงการบันทึกด้วยตัวเอง

⚙ เชื่อมต่อ API แยกแต่ละบริการ

สมาชิกแต่ละคนเก็บคีย์ส่วนตัวแบบเข้ารหัส · ไม่แชร์คีย์ให้ผู้ใช้หรือแอดมินผ่านหน้าเว็บ

คีย์ API ไม่ใช่รหัสผ่านบัญชีร้านค้า อย่าใส่ OTP หรือรหัสผ่าน Shopee/TikTok ที่นี่ · สถานะ “บันทึกแล้ว” ไม่ได้ยืนยันว่ามีเครดิต หรือใช้สร้างวิดีโอได้

🔐 เปลี่ยนรหัสผ่าน

อุปกรณ์อื่นที่ล็อกอินบัญชีนี้อยู่จะถูกออกจากระบบ

คำแนะนำการเชื่อม

Grok Imagine: ใช้ xAI API key ที่มีเครดิตแยกจากการใช้ Grok ในแอป · Google Veo: ใช้ Gemini API key ที่ได้รับสิทธิ์สร้างวิดีโอ (อาจมีค่าใช้จ่ายแยกจาก Flow) · OpenRouter: ใช้คีย์จาก openrouter.ai/keys และเติมเครดิตล่วงหน้า คีย์เดียวเลือกได้หลายรุ่น · Brave Search: ใช้คีย์ค้นหาเว็บ · TikTok/Shopee: การโพสต์ต้องขอ OAuth/สิทธิ์แพลตฟอร์มก่อน
