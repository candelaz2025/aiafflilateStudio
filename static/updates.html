⬆ ศูนย์อัปเดตระบบ

เวอร์ชันที่ติดตั้ง: กำลังตรวจสอบ...

การอัปเดตจะสำรองข้อมูลบัญชี/คีย์และเก็บไฟล์เดิมไว้ในโฟลเดอร์ updates/backups ก่อนเปลี่ยนโค้ด แต่ไม่แทนที่ข้อมูลสมาชิกเดิม

อัปเดตบน Windows

  1. ดาวน์โหลดไฟล์แพตช์ ZIP จากช่องทางที่เชื่อถือได้
  2. ปิดหน้าต่าง CMD ที่เปิดโปรแกรมนี้อยู่
  3. นำไฟล์ ZIP ไปใส่โฟลเดอร์ updates/inbox (ใส่ครั้งละ 1 ไฟล์)
  4. ดับเบิลคลิก update_windows.bat แล้วเปิด run_windows.bat อีกครั้ง

สำคัญ: V7.4 เพิ่ม Studio ส่วนตัวของสมาชิกและจำกัด Beta 100 บัญชี แต่ยังไม่รองรับการโพสต์และสร้างวิดีโออัตโนมัติในบัญชีสมาชิก การเปิดเว็บออนไลน์ต้องทดสอบความปลอดภัยและใช้ HTTPS ก่อน
