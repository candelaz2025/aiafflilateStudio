ขั้นตอนการอัปเดตบน Windows

1
ดาวน์โหลดไฟล์แพตช์ ZIP เวอร์ชันใหม่จากช่องทางทางการที่เชื่อถือได้
2
ปิดหน้าต่าง Command Prompt / Terminal ที่กำลังรันระบบอยู่
3
นำไฟล์ ZIP ไปวางในโฟลเดอร์ updates/inbox (ใส่ครั้งละ 1 ไฟล์)
4
ดับเบิลคลิกไฟล์ update_windows.bat แล้วเปิด run_windows.bat อีกครั้ง
