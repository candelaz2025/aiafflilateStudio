🔑 รหัสผ่านชั่วคราว

แสดงครั้งเดียว ระบบไม่ได้เก็บรหัสนี้ไว้ · ส่งให้สมาชิกทางช่องทางส่วนตัว แล้วให้เปลี่ยนรหัสที่เมนู API ของฉัน → เปลี่ยนรหัสผ่าน

👥 สมาชิก

รหัสผ่านและ API key ของสมาชิกไม่แสดงในหน้านี้ · “คีย์ของตัวเอง” แสดงเฉพาะชื่อผู้ให้บริการที่บันทึกไว้

#ชื่อผู้ใช้อีเมลสิทธิ์สมัครเมื่อล็อกอินล่าสุด*สินค้าบทคลิป (สำเร็จ/ทั้งหมด)โควตาฟรีค่าใช้จ่ายฟรีเดือนนี้คีย์ของตัวเองจัดการ

* ประมาณจากเซสชันล่าสุด (เซสชันมีอายุ 7 วัน) · ค่าใช้จ่ายเป็นราคาประมาณจากรายการราคา OpenRouter ไม่ใช่ยอดที่ถูกหักจริง

🧾 ประวัติการจัดการของแอดมิน
