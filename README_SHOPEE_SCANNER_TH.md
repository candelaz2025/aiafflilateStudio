# V7.10 · Shopee Affiliate Scan & Import

## ความสามารถจริง
- หน้า Product Radar มีส่วน “สแกน/นำเข้าข้อมูล Shopee Affiliate”
- สมาชิกเปิดหน้า Shopee Affiliate ในเบราว์เซอร์เอง แล้วคัดลอกชื่อสินค้า ลิงก์ ราคา และ Extra Comm (ถ้ามี) มาวางในเว็บเรา
- รองรับ CSV ที่สมาชิกดาวน์โหลดจากหน้า Shopee Affiliate โดยตรง (ต้องมีคอลัมน์ชื่อสินค้า)
- แสดงผลก่อนบันทึก (สูงสุด 100 รายการสำหรับ CSV), เลือกบันทึกสินค้าในบัญชีตัวเอง, ส่งไปสร้างบทผ่านเมนูสินค้าของฉัน
- แยกข้อมูลบัญชีด้วย session + CSRF เดิม การอ่านรายงานไม่เก็บไฟล์ต้นฉบับไว้บนเซิร์ฟเวอร์
- ไม่มีการขอรหัสผ่าน Shopee, ดักคุกกี้, ข้าม CORS หรือส่งคำขอไปยัง Shopee จากเว็บเรา

## ข้อจำกัด
**ไม่ใช่เครื่องมือดูดข้อมูลจากหน้าที่ล็อกอินใน Shopee อัตโนมัติ** ข้อกำหนด Shopee Affiliate จำกัดการสแกนข้อมูลอัตโนมัติที่ไม่ได้รับอนุญาต การดึงแบบอัตโนมัติเต็มรูปแบบต้องมี API/การอนุญาตอย่างเป็นทางการ
- ตัวเลขในข้อความ/CSV เป็นข้อมูลที่สมาชิกนำเข้ามา ไม่ใช่ค่าคอมยืนยันโดย Shopee API
- ส่งรายงาน CSV ที่มีชื่อสินค้า; รายงานยอดรวมที่ไม่มีคอลัมน์ชื่อสินค้า ระบบจะแจ้งข้อผิดพลาดแทนการสร้างข้อมูลปลอม
- Extra Comm จากข้อความเป็นเพียงเบาะแสและไม่ติดป้ายยืนยันเอง
