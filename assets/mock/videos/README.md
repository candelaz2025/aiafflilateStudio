# คลิปตัวอย่างสำหรับโหมดจำลอง (VIDEO_MOCK=1)

วางไฟล์ `.mp4` ไว้ในโฟลเดอร์นี้ แล้วระบบจะสุ่มเลือกคลิปจากที่นี่เป็นผลลัพธ์ของงานจำลอง (แต่ละงานได้คลิปเดิมเสมอ)

- แนะนำ: แนวตั้ง 9:16 (เช่น 720×1280) ยาว ~8 วินาที, H.264 + `-movflags +faststart` เพื่อให้เล่นในเว็บได้ทันที
- ขนาดไฟล์ไม่เกิน ~10 MB ต่อคลิป (ไฟล์อยู่ใน Git และใน Docker image)
- ถ้าโฟลเดอร์นี้ไม่มี `.mp4` ระบบจะใช้ `assets/mock/default.mp4`
- เพิ่มไฟล์แล้ว commit + push → Railway deploy ใหม่ให้เอง

ปิดโหมดจำลองเมื่อพร้อมใช้ AI จริง: ลบ `VIDEO_MOCK` หรือตั้งเป็น `0` ใน Railway → Variables แล้วใส่ `PLATFORM_OPENROUTER_API_KEY`
