# Affiliate Auto Studio — PC V6

**แก้ปัญหาสแกนสินค้าแล้วได้ 0 รายการ** · เว็บแดชบอร์ดภาษาไทยสำหรับ Windows · ใช้ร่วมกับ TikTok Affiliate / Shopee Video และ Google Flow (เปิดเว็บเอง) หรือ Gemini Veo API (เมื่อมีสิทธิ์และคีย์)

## ติดตั้งบน Windows (ต้องมี Python 3.11 ขึ้นไป)

1. แตกไฟล์ ZIP ไว้ในโฟลเดอร์ที่ต้องการ **ไม่ต้องเอาไฟล์ V6 ไปทับ V5**
2. ดับเบิลคลิก `run_windows.bat` เท่านั้น (อย่าเปิด `app.py`)
3. ครั้งแรกโปรแกรมติดตั้งไลบรารีที่ต้องใช้ จากนั้นเปิดเบราว์เซอร์ให้อัตโนมัติ ถ้าเบราว์เซอร์ไม่เปิด ให้ดู URL ใน CMD แล้วพิมพ์ตามที่แสดง (`http://127.0.0.1:8000` หรือพอร์ตสำรองหาก V5 เปิดค้าง)
4. หน้า **ค้นหาจากเว็บภายนอก** มีตัวอย่างหัวข้อสำหรับตรวจสอบอยู่แล้ว กด **สแกนตอนนี้** เพื่อค้นจาก Google Trends / Google News หากทั้งสองไม่มีรายการ จะคงหัวข้อค้นคว้าไว้เป็นจุดเริ่มต้น
5. ไปหน้า **⚙ ตั้งค่าการเชื่อมต่อ** เพื่อใส่ API key ในเบราว์เซอร์บนคอมเครื่องที่เปิดโปรแกรมโดยไม่ต้องแก้ `.env` ด้วยมือ ระบบเก็บค่าลง `.env` บนเครื่องเท่านั้น
6. หน้า **⚡ ออโต้ 24/7** เปิดโหมดสแกนตามรอบและเตรียมบทของสินค้าที่มีหลักฐานลิงก์ Affiliate ที่ผ่านการตรวจสอบแล้ว

## สถานะความสามารถจริง

| ฟังก์ชัน | ตอนเปิดครั้งแรก | ต้องมีอะไรเพิ่ม |
|---|---|---|
| เปิดเว็บแดชบอร์ด Windows อัตโนมัติ | ✅ | Python + การติดตั้งไลบรารีครั้งแรก |
| มีหัวข้อสินค้าที่น่าค้นคว้า (ไม่ใช่ยอดขายยืนยัน) | ✅ | ไม่มี |
| สแกน Google Trends / Google News | ✅ เมื่อออนไลน์ | อินเทอร์เน็ตและเว็บต้นทางตอบกลับ |
| เขียนบท แคปชั่น Prompt POV ภาษาไทย | ✅ เทมเพลต | API เสริมถ้าต้องการ AI เขียนแบบปรับได้ |
| ค้นลิงก์ SKU ใน TikTok / Shopee ผ่าน Brave Search | ยังไม่เปิด | Brave API key + ต้องตรวจว่าสินค้าตรงรุ่นเอง |
| แสดงยอดขายและค่าคอมจริง | ยังไม่เปิด | ฟีด/CSV จากแหล่งที่ได้รับอนุญาต |
| เจนวิดีโอด้วย **Google Flow เว็บไซต์** โดยตรง | ❌ | ต้องเข้า Flow เองและนำไฟล์กลับเข้าโปรแกรม ไม่มี API ของหน้า Flow ที่ใช้ในรุ่นนี้ |
| เจนด้วย **Google Veo API** โดยอัตโนมัติ | ⏳ | Gemini API key ที่ใช้งาน Veo ได้ + เครดิตจ่ายตามบริการ + สินค้า/ภาพอ้างอิงที่มีสิทธิ์ใช้ |
| โพสต์ TikTok ผ่าน API อย่างเป็นทางการ | ⏳ | TikTok Developer App, `video.publish` ผ่านอนุมัติ, OAuth, การยืนยันรายละเอียดคลิป |
| โพสต์ Shopee Video และปักตะกร้าทั้งสองแพลตฟอร์มอัตโนมัติ | ❌ | **ยังไม่มีช่องทางเชื่อมต่อที่รุ่นนี้ยืนยันรองรับ** ต้องทำในแพลตฟอร์ม |

### ทำไมมีสินค้าให้ดูแต่ยังไม่เรียกว่า 'ขายดี'

Google Trends คือกระแส **คำค้นหา** ไม่ใช่ยอดขาย; Google News คือบทความซึ่งยังไม่ยืนยัน SKU; หัวข้อเริ่มต้นเป็นเพียงสินค้าที่ควรไปศึกษาเพิ่มเติม **ไม่ใช่ข้อมูลยอดขายหรือคอมมิชชัน**. ระบบจะไม่เอาหัวข้อที่ยังไม่ยืนยันไปทำคลิปขายหรือเผยแพร่อัตโนมัติ

### อยากให้รันทุกอย่างเองที่สุดเท่าที่ทำได้

- เปิดคอมทิ้งไว้ ปิดโหมด Sleep ระหว่างใช้งาน
- ไปหน้า **⚡ ออโต้ 24/7** เปิดระบบ, ค้นหากระแส และเตรียมบท จากนั้นบันทึกและกดสั่งทำงานหนึ่งรอบ
- ระบบจะไม่สั่งจ่ายค่าเจนวิดีโอจนกว่าคุณจะเปิดตัวเลือก `สร้างวิดีโอ` และตั้งจำนวนจำกัดต่อวัน
- ต้องยืนยันสินค้า Affiliate และสิทธิ์ปักตะกร้าของบัญชีตัวเองก่อนอนุญาตให้สคริปต์เข้าสู่คิว
- TikTok ต้องดู/อนุมัติคลิปก่อนโพสต์ และ Shopee Video รุ่นนี้ยังเป็นคิวเตรียมคลิป ไม่ใช่โพสต์อัตโนมัติ

### ย้ายข้อมูล V5

V6 สร้างฐานข้อมูลที่ `data/studio.db` ภายในโฟลเดอร์ V6 แยกจาก V5 โดยอัตโนมัติ ถ้าคุณเคยมีข้อมูลสินค้าหรือคลิปใน V5 ให้ปิดโปรแกรมทั้งสองก่อน จากนั้นคัดลอกโฟลเดอร์ `data` ของ V5 มาใส่โฟลเดอร์ V6 (สำรองก่อนทับ). ห้ามย้าย `.venv` ของ V5 มาใช้

### ความปลอดภัย

- คอมควบคุมผ่าน `127.0.0.1` ในเครื่องตัวเองเท่านั้น ไม่มี public server
- อย่าส่ง API key, TikTok password หรือ OTP ให้ใคร
- ไฟล์ `.env` เก็บคีย์ในรูปข้อความบนเครื่อง อย่าแชร์/ส่ง ZIP ทั้งโฟลเดอร์ที่มีไฟล์นี้
- หน้า UI จะไม่แสดงคีย์เดิมหลังบันทึก
- สิทธิ์ TikTok และ Shopee ไม่ได้เชื่อมสำเร็จเพียงเพราะติดตั้งโปรแกรม

### ตรวจสถานะ/ทดสอบ

- หน้า Dashboard: `/`
- สถานะสุขภาพ: `/health`
- ตรวจสอบคำสั่ง: `python -m pytest -q tests` (ติดตั้ง pytest กับ httpx เพิ่มสำหรับทดสอบ)
- หากโปรแกรมขึ้นปัญหา ให้ถ่ายภาพหน้าต่าง CMD เฉพาะข้อความผิดพลาด ไม่ต้องส่ง API key
