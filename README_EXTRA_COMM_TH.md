# Product Radar Extra Comm Hunter · V7.7

- ใน Product Radar ติ๊ก **เน้น EXTRA COMM (Shopee)** แล้วค้นชื่อสินค้า ระบบใช้ผลเว็บภายนอกเป็นเพียงเบาะแส **ไม่รับรองว่าสินค้านั้นยังได้ค่าคอมพิเศษ**
- หากผลค้นหา 0 รายการ ให้เปิดโปรแกรม Affiliate ใน Shopee ตรวจป้าย **Extra Comm** ตามคำแนะนำทางการ: https://help.shopee.co.th/portal/10/article/123905
- หลังตรวจสอบกับบัญชีตนเอง ให้เปิด **สินค้าของฉัน** เลือก Shopee กรอกชื่อ/ลิงก์ Shopee แล้วติ๊ก “ตรวจจากบัญชี Shopee แล้วว่ามี EXTRA COMM” ใส่เรท % ตามที่ปรากฏจริง (ถ้าทราบ)
- ระบบเก็บป้าย **ยืนยันโดยสมาชิกเอง** และวันตรวจเท่านั้น ไม่ได้อ่านเรท Shopee โดยตรง และอัตราอาจเปลี่ยนแปลงได้
- API `/api/my/products` จะแยกสินค้าและเรทตามบัญชี มี `PATCH /api/my/products/{id}/extra-comm` เพื่อแก้เรทได้
- ถ้าอัปเกรดจากเวอร์ชันก่อน ระบบเติมคอลัมน์ฐานข้อมูลอัตโนมัติ; โปรดสำรอง data และ master key ก่อนอัปเดต
- ไม่ต้องให้รหัสผ่าน Shopee / OTP กับโปรแกรม และยังไม่ได้โพสต์/ปักตะกร้าอัตโนมัติ
